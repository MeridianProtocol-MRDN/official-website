# Security Policy

## Reporting a vulnerability

If you find a security issue in this website's code or the deployment
pipeline, please report it privately rather than opening a public issue.

Email: **admin@meridianprotocol.site**

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact

## Scope

This policy covers the website codebase in this repository and its
deployment configuration. For issues with the MRDN smart contract itself,
see the [security status page](https://meridianprotocol.site/security) and
[vulnerability disclosure policy](https://meridianprotocol.site/security-policy).

## Response

This is an early-stage, small project. Response times are best-effort. You
will receive an acknowledgment once a report is reviewed.
